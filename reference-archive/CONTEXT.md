# reference-archive（参考归档）

把官方散落资料固化成一份本地可离线查阅、出处可回溯、不确定处显式标注的参考库。

## Language

**归档（archive）**：
一个目录，内含编号 Markdown、资源镜像与一手资料镜像。它是**产物**；本技能是**生产它的方法**。
_Avoid_: 文档库、资料库、知识库、wiki

**原文存档**：
官方页面转写成的 Markdown，正文一字不改，只加「来源 / 采集时间」头部。
_Avoid_: 备份、快照、镜像、存档副本
（与「一手资料镜像」的区别：原文存档是**转写**，一手资料镜像是**逐字节副本**。）

**一手资料镜像**：
上游仓库、固件二进制、数据手册 PDF 的**逐字节副本**，只存不改，附 sha256 与来源。
_Avoid_: 存档、缓存、vendor、依赖

**整理文档**：
由多路来源交叉核对后写出的派生结论，每条标出处。
_Avoid_: 报告、分析、笔记、总结
（与「原文存档」的区别：整理文档是**判断**，原文存档是**转写**。两者混在一份文件里，读者无法判断哪句话是官方说的、哪句话是推断的。）

**出处标记**：
整理文档里标注结论来源的固定标签（如【原理图】【BSP】【文档】）。同一份文档内含义必须恒定。
_Avoid_: 引用、注释、标记、来源标签

**不确定项**：
无法验证、来源互相矛盾、或只能靠推断的条目。集中成节，写明冲突双方与判定条件。
_Avoid_: 存疑、待确认、风险项、遗留问题
（与「遗漏」的区别：遗漏是**没做**，不确定项是**做了但没有定论**。）

**交叉验证**：
对同一条硬件事实，从多个**独立性不同**的来源分别取证并逐项比对。
_Avoid_: 多方核实、印证、对账、验证
（与「对账」的区别：交叉验证比的是**多条证据链的一致性**，对账比的是**两个版本快照的差异**。）

**对账（增量对账）**：
把上游新快照与本地归档快照逐文件比对，产出新增 / 删除 / 变更三张表。
_Avoid_: 同步、diff、比对、核对差异

**改名未改码**：
上游把目录整体搬家，但文件内容 sha1 全部相同。逐文件对账才能识破，假大改会连带改坏技术结论。
_Avoid_: 移动、重命名、无实质变更

**实例（case）**：
一次真实归档的完整记录，留在 `references/` 里演示方法怎么落地。它是**教学材料**，不是**通用结论**。
_Avoid_: 案例、样例、范例、demo
