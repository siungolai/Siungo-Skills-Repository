# 格式细则：横式公函、直式公函、信封、联署信

源自《政府公文写作手册（第三版）·公函》"格式样本"及"延伸阅读：联署信"（原书第 6–14 页）。

## 一、横式公函 14 个组件（按信笺自上而下顺序）

| # | 组件 | 规则 |
|---|---|---|
| 1 | 部门信笺 | 撰写公函应用部门信笺 |
| 2 | 机密／递送方式 | 属机密级别者，在信笺上方中央注明机密程度；以挂号、专人派递等特别方式送递者，在信笺右上方注明（如"专递急件"） |
| 3 | 本函档号 (Our Ref.) | 信笺左上方预留位置，注明所发函件档号 |
| 4 | 来函档号 (Your Ref.) | 标明来函档号，方便收信人归档、翻查和跟进 |
| 5 | 收信人地址及姓名 | 先写地址，然后写收信人所属机构名称及职衔，最后才写收信人姓名及称谓。发予内部人员的信可略去地址，直接写职衔、姓名及称谓，需要时加所属组别 |
| 6 | 上款 | 写收信人姓氏，后面加称谓（详见 address-terms.md），后加冒号 |
| 7 | 标题 | 可因应需要在正文首段上方中央位置加标题，扼要说明主题，可用粗体或加底线。酬酢性质公函（谢函、慰唁信）或内容简单、篇幅较短者一般不加标题 |
| 8 | 正文 | 内容复杂者宜分段书写；每段首行缩入两格（留空两个全形字位）。一般不标注段次；如有需要，可用阿拉伯数字，并由第二段开始标注 |
| 9 | 祝颂语／问候语 | 可视乎情况加上，紧接上文或另段书写均可 |
| 10 | 下款 | 写在正文之下信笺右方，与正文和纸边宜有适当距离。由机关首长授权属下人员签发的公函，下款先列首长职衔，下一行写代行人姓名并加括号；代行人职衔通常无须注明，确有需要也可具列。**署名后不用加"谨启、谨复"等启告语** |
| 11 | 签署／盖章 | 发信人或代行人可签署或盖章 |
| 12 | 附件 | 如有附件，注明"连附件"或把附件逐一列出（如"△△表格一式三份"） |
| 13 | 副本 | 另发副本应注明"副本送"或"副本分送"，列出副本受文人；每名受文人后可加注"不连附件"、"经办人：……"等；副本存档用"副本存"＋档案编号 |
| 14 | 日期 | 自成一行，写在信末左下方。汉字或阿拉伯数字均可，但要通篇一致 |

## 二、直式公函

- 较多用于酬酢场合，可沿用传统书信格式；内文开首不必写上收信人地址。
- 档号：信笺印有"本函档号／来函档号"者写在预留位置，否则可在信笺右上方上款前面写上档号。
- 标题：可因应需要加，用粗体字标示。
- 正文：段落不标注段次，每段首行留空两个全形字位。
- 下款：与信笺下方宜留有适当空间；由代行人发出者，机关首长与代行人分行写出。
- 日期：自成一行，写在信末**左上方**；为方便阅读，直式公函日期应以汉字书写。
- 内文提及数字，应尽量用汉字书写。
- 横式公函注释中关于信笺、档号、机密标注、上款、祝颂语、签署、附件、副本的原则同样适用。

## 三、信封格式

1. 先写地址，然后写收信人所属机构名称及职衔，最后写收信人姓名及称谓。地址写法：先地区，再街道名称、门牌号数、楼宇名称、座数、楼层、单位。
2. 收信人称谓之后加开启语：一般多用"收启"、"启"；如要表示尊敬，可用"台启"。
3. 政府机关往来公函如经由政府内部收发系统派递，信封面可略去地址，但必须清楚写上收信人的职衔或姓名；如有需要，也可注明经办人的职衔和姓名。

示例：

```
九龙长沙湾
荔枝角道△号
△△花园第△座△楼△室
△△协会主席
△△△先生台启
```

## 四、联署信的回复规则

回复联署信，复函一般可直接寄给来函指明的联络人，无须逐一回信给联署人。来函没有注明联络人时：

**1. 联署人来自同一机构或用同一回邮地址**
- 联署人数众多、不便尽列：以来函下款首名联署人为收信代表。
  - 地址部分：`[机构地址／回邮地址]`＋`张△△先生`
  - 上款：`张先生及各位联署人：`
- 只有两三名联署人：可按来函下款署名次序全部列出。
  - 地址部分：`温△△议员、汤△△女士、林△△先生`
  - 上款：`温议员、汤女士、林先生：`
- 联署人姓氏相同：上款宜具列全名以资识别，如"陈△△主席、陈△△会长、黄△△理事长："。

**2. 联署人分属不同机构**
- 以回邮地址决定谁人代表收信；无法确定回邮地址谁属，则以来函下款首名联署人为收信人。

**3. 机构联署信**
- 多家机构联署来信但没有注明负责人姓名及职衔：收信代表可以是提供回邮地址的机构，或来函下款居首的机构。
  - 地址部分：`[回邮地址／居首的联署机构地址]`＋`[机构名称]`
  - 上款：`执事先生：`
- 建议在内文请收信代表把复函内容转达其他联署机构，并在信末列出其他机构名称，方便跟进。
