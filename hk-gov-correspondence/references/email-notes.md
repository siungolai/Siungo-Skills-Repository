# 公务电子邮件：结构、格式与 11 项注释

源自原书第 109–112 页"电子邮件·注意事项"。

## 一、总原则

- 电邮与一般公函一样应尽快回复。
- 电邮虽在结构和行文要求方面没有一般书信那样严格，但实际上也是书信一类：撰写时同样应以**条理分明、用字简洁而且合乎语法**为原则；行文须得体有礼，按情况和收件对象选词用字。
- 网络或社交平台上使用的**表情符号和代号，不宜用于公务电邮**。
- 内容过长或提述太多信息，在电脑屏幕上不易阅读：可把详细资料以附件形式送出，或加入链接让收件人浏览。加入附件或图像时注意不要令电邮档案过大，影响传送和接收。

## 二、基本结构

```
寄件人：am_to@abc.gov.hk
收件人：my_tong@xyz.com.hk
标题：△△△△
日期：20△△年△月△△日（一般由电脑自动注明）
副本送：yy_lee@abc.gov.hk

△先生：

  正文（分段，段间留空一行）……

△△署
△△主任（公共事务）△△△
电话：4321 12△△
传真：1122 33△△
```

## 三、11 项注释

1. **标题**应扼要明确，帮助收件人决定处理邮件的缓急次序，也便于日后分类存档。属回复邮件，宜沿用**来件的标题**，方便辨识。
2. 即使信息非常简短，也不宜把内容写在标题栏内而把正文留空。
3. **日期**一般在电邮发出时由电脑自动注明，无须在正文下款之下重复。
4. **副本**：收件人可从页首"副本送："（cc）一栏看到副本发送到哪些地址，正文可无须重复。如有需要清楚说明，可在文内注明"本电邮同时发给〔职衔〕〔姓名〕。"；如有多人收取副本，也可在下款之下加副本分送名单（一般公函做法）。
5. **上款**：属回复邮件，上款称谓根据来件下款的姓名处理。对方未具名、电邮地址又未显示姓名，可省略上款；来件下款只有机构或团体名称，回邮上款可用"执事先生"；收件人为一组人，可按情况用"各位同事"、"各位代表"等；内部邮件内容简单且收件人身分明确，可考虑略去上款。
6. **正文排版**：可全部靠左对齐，或每段首行留空两格；段落之间应留空一行。篇幅较长可采用一般公函做法，每段标注段次或分项列出，务求层次分明。
7. **强调**：可用斜体、粗体或其他字体颜色突出某部分内容，但不宜滥用，以免效果适得其反。
8. **附件**：如夹附电脑档案，宜在正文述明。回复时一般选择**不包括原电邮的附件**，以免附件随回复重复送出多次。
9. **下款**：发给市民或外间机构／团体的电邮，下款应注明寄件人所属部门、职衔和姓名；如有必要也可由代行人发出。内部电邮可用个人或组别名义发出；寄件人身分明确也可省却下款。**电邮若写上上款，则下款不宜略去**。下款可与正文一样靠左对齐。
10. **共用邮件户口**：收件人无法从电邮地址辨识寄件人，寄件人尤须注意在下款交代身分。
11. **联络资料**：寄件人可在下款之下加上电话、传真等其他联络资料，方便对方查询或跟进。
