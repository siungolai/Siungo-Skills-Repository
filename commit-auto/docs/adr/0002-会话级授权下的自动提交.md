# 会话级授权下的自动提交

用户的既有硬性偏好是「没有我的允许确认，禁止 commit 和 push 到 GitHub」。commit-auto 用**会话级授权**化解这个冲突：用户在会话开始时显式授权后，该会话内每个提交单元闭合即自动提交，不再逐次打断；未获授权时退回逐次确认，而不是完全不提交。

替代方案有两个，都被否决：全程无人值守自动提交——它直接覆盖了既有的硬性偏好；逐次确认——它让「自动」这个前提失去意义，技能退化成 commit-report 的一层空壳。

授权同时**覆盖审阅门的确认步骤**：`commit-report` §4 的回应判定由会话级授权一次性给出，自动模式下列出审阅要素后直接提交，不再逐笔等待。审阅门被复用的是它的分析、风格匹配与安全边界（单一事实源），而不是它的等待。授权是否覆盖 push，见 ADR-0003。
