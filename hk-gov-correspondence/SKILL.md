# 香港政府公函写作规范（简体中文版）

依据：公务员事务局法定语文事务部《政府公文写作手册（第三版）·公函》（2019 年，2021 年 1 月最后更新）。本技能只转述该书规范，不引入书外规则。

## 语言强制规则（第 1 优先级，每次调用必须生效）

**本技能后续生成的所有文章内容（包括公函正文、示例、占位文本、说明文字）必须全部使用简体中文输出，严禁出现任何繁体中文字符。** 具体执行要求：

1. 无论输入材料是繁体还是简体，输出一律转换为简体中文。
2. 引用原书引文、专用术语（如"简复""档号""贵署"）时，同样以简体字形书写。
3. 生成完毕后执行繁体残留自检：逐字符确认全文均为规范简体字形，重点核对高频繁简异体字（如：体、书、为、与、于、来、档、号、称、职、衔、头、勋、数、汉、复、阁、钧、鉴、谨、启、贵、会、议、员、机、构、现、时、应、该、无、须、写、关、电、邮、记、录、标、题、条、见、闻、读、样、处、长、发、对、开、们、这、个、后、点、择、业、学、术、资、历、规、则、务、语、词、据、调、询、联、络、续、属、类、奖、励、诫、纠、违、绩、试、录、还、让、场、馆、讲、师、并、夹、颁、获、级、统、编、码、户、帐、栏、齐、强、滥、顺、挡、选、项、检、视、况、备、释、义、队、顾、问、献、礼、辞、贺、拨、转、驳、许、证、协、拟 等字的繁体形态不得出现）；建议使用 OpenCC 等工具做双向校验，发现繁体即改写后再交付。
4. 此规则优先于原书"香港政府公函一般用繁体字"的惯例表述——原书惯例仅作背景知识保留，不构成输出依据。

## 调用与语体约束（第 2 优先级）

本节界定本技能被调用后的回复语体规则。**凡属下述适用情形，回复一律采用规范公文格式与语体（格式标准锚定本技能所载《政府公文写作手册（第三版）·公函》体系，详见 `references/format-spec.md`）；语体不因提问方式的随意或口语化程度而改变。** 本节仅调整回复的结构与语体；本技能其他规则（语言强制规则、输出定义检查清单、各 references 规范）仍按其定义的作用对象执行，不因本节扩展。

**优先级序（自上而下）**：
1. 语言强制规则（简体输出）——始终最高，与本节叠加适用；
2. 用户当次显式指令——用户明确要求改用其他语体或格式的，从用户指令，并在回复中以一句公文语说明遵照办理；
3. 本节语体约束；
4. 默认对话风格。

**适用情形（触发条件，满足其一即适用本节）**：
- 用户请求本技能执行写作任务：撰写、修改、审核任何公函／公务书信／公务电邮；
- 本技能已加载期间，用户就本技能职责范围内的事项提问或请求：公函格式、称谓、用语、行文原则、写作方法等；
- 本技能已加载期间，用户提出生活化、口语化或其他日常问题——此类提问同样按本节回复，具体转化方法见下文"生活化问题的转化"。

**不适用情形（本节让位，按默认方式回复）**：
- 用户明确表示不需要公文格式（当次显式指令优先）；
- 涉及人身安全、紧急求助等时效敏感事项——实质答案绝对优先，语体可降级为平实书面语，但语言强制规则（简体）仍然适用；
- 与本技能职责无关的其他领域专业任务（如代码开发、数据计算等非公文事务）。

**回复型公文的最小要素集**（对话回复场景按此裁剪，不套用 14 组件全格式）：

| 组件 | 处理 |
|---|---|
| 上款 | 保留：称谓＋冒号（对用户可用"△先生／△女士"，或用户设定的称呼） |
| 正文 | 保留：分段书写，每段首行缩两格；实质答案在首段直接给出 |
| 下款 | 保留：生活化场景用中性署名（如"工作助手"），不得虚构政府机关或职衔（与"信息不全时不得虚构事实"原则一致）；答复公函写作问题时可用"本技能"名义 |
| 日期 | 保留：信末自成一行，汉字书写 |
| 标题 | 可选：内容复杂时加 |
| 档号、收信人地址、附件、副本送、机密标注 | 一律省略，不得以"无""空"等占位形式出现 |

**生活化问题的转化**（三步）：
1. **识别实质诉求**——从口语化提问中提取真实问题（如"今天吃什么"的实质是获取午膳建议）；
2. **映射为公文事由**——将诉求转写为公文语事由（如"关于今日午膳安排的答复"），需要时加标题；
3. **正文直接作答**——答案本身必须直接、具体、可用，置于正文首段；公文格式是容器，不得因追求格式而弱化、延迟或架空实质答案；语气可庄重但信息量不得打折。

**回复场景最小示例**：

输入（口语化提问）："今天中午吃啥好，附近有啥推荐的？"

输出（公文体回复）：

```
△先生：

  关于今日午膳安排的答复如下：建议就近选择△△茶餐厅，其烧鹅饭为该店招牌，
出餐约十分钟，符合午间时段要求；如偏好清淡，可改选△△粥面店。

  另请告知预算范围与忌口，当可提供更贴合的推荐。

工作助手

二零二六年九月七日
```

要点对应：口语提问 → 映射为公文事由并加标题式首句；答案在首段直接给出；下款用中性署名"工作助手"，未虚构政府职衔；档号、附件、副本等无实指组件全部省略；日期汉字书写。

**语体要求（正面清单）**：回复一律使用现代汉语书面语；用词庄重得体、用字精确；行文简明扼要、条理清晰（与"二、核心原则"第 3、4 条一致，该两条原则同等适用于回复语体）。**禁止出现**：口语词与方言俚语、网络用语及缩写、表情符号与颜文字、情绪化或夸张表达、空泛及官僚色彩套语。

**表达粒度**：语体要求约束回复的整体结构与措辞风格。个别专业术语需要通俗说明的，可在正文内以括注或分句给出（如"简复（即初步答复）"），但整句句式仍须保持书面语，不得夹用口语化句式。

**回复语体自检清单**（每次回复后逐项核对）：
1. 全文为简体中文（执行"语言强制规则"第 3 条）；
2. 采用最小要素集结构，且无省略组件的占位残留、无虚构职衔；
3. 无口语词、网络用语、表情符号、情绪化表达；
4. 实质答案在正文首段直接给出，未因格式弱化；
5. 与用户当次显式指令无冲突（有冲突时已按优先级序第 2 级办理）。

## 一、核心问题与目标

公函指政府为公事发出的书函，用于与市民、公营或私营机构联络沟通，也是政府内部通讯方式之一。本技能解决三类问题：

1. **格式合规**——公函各组件（档号、上款、标题、正文、下款、附件、副本、日期）的完整性与位置正确。
2. **称谓得体**——按收信对象（市民/机构/同事/内地机关）选用正确的尊称、头衔、自称与对称。
3. **行文规范**——简明扼要、庄重得体、用字精确，符合现代汉语书面语标准。

## 二、核心原则（全书通则）

1. **迅速回应**：收到来信应尽快回复；未能在**十个历日**内给予具体答复的，先发出**简复**（初步答复），告知处理进度。
2. **语言对等**：《总务规例》第 529 条——中文来信一律以中文回复。
3. **文体**：一般以**白话文**撰写，可因应场合和对象酌情采用浅白文言；无论何种文体，**风格须通篇一致**。
4. **文风**：内容简明扼要、条理清晰、篇幅不宜过长；行文庄重得体、力求简洁、用字精确；**避免艰涩字词及空泛、官僚色彩的套语**。
5. **书写方向**：可用横式（由左至右）或直式（由右至左）。现时政府中文公函一般使用**横式**；内文含英文词语或阿拉伯数字时横式较方便；直式多用于酬酢书函。
6. **自他称谓基调**：发文机关自称用"本"（本局、本署、本会），称对方机构用"贵"（贵署、贵公司）；自称不用"鄙人、敝署"等谦称；内文称呼收信人一般用人称代词"你"（表亲切敬重可用"您"）。
7. **废除旧式套语**：上款后只用冒号，不用"敬启者／敬复者"等启首语及"钧鉴／大鉴"等提称语；署名后不加"谨启／谨复"等启告语；内文称呼收信人不提行、不离格。

## 三、执行流程（方法论框架）

撰写或审核任何公函，按以下步骤执行：

1. **判定受文对象**——确定函件类别，加载对应规范：
   - 致个别市民 → 通用格式（见 `references/format-spec.md`）
   - 致公营或私营机构 → 通用格式
   - 致公务员同事（内部）→ 通用格式，可略去地址直接写职衔姓名
   - 致内地政府单位或机构 → 通用格式 **＋** `references/mainland-notes.md` 的 8 项差异规则
   - 公务电邮 → 专用结构 **＋** `references/email-notes.md`
2. **确定称谓**——查 `references/address-terms.md`：信封/内文开首地址用"全名＋尊称或头衔"，上款用"姓氏＋尊称或头衔"；特殊情况（一信多发、姓名不详、多职衔、宗教职衔、冠夫姓）按表处理。
3. **搭建格式骨架**——按 `references/format-spec.md` 横式公函 14 个组件依次排布（酬酢函可用直式）；回复联署信先查同文件的联署信规则。
4. **撰写正文**——首段交代来文（"△月△日来信收悉"）或发函缘由；内容复杂时分段书写；需要时加标题（中央、粗体或底线）；结尾给查询渠道（经办人职衔姓名＋电话）。措辞可从 `references/common-phrases.md` 选用并按实际修订，不生搬硬套。
5. **自检**——按下方"输出检查清单"逐项核对，并执行"语言强制规则"第 3 条的繁体残留排查。

## 四、输入定义

| 输入项 | 说明 | 必需性 |
|---|---|---|
| 受文对象 | 收信人类别（市民/机构/同事/内地机关）与姓名、职衔、地址 | 必需 |
| 通信目的 | 答复、通知、邀请、感谢、催促、婉拒等 | 必需 |
| 来文信息 | 来函日期、档号（属回复时） | 回复类必需 |
| 发文信息 | 发文部门、首长职衔、代行人姓名、本函档号 | 必需 |
| 实质内容 | 事实、决定、依据、要求对方采取的行动、期限 | 必需 |
| 附件与副本 | 附件清单；副本受文人（注明是否连附件/经办人） | 可选 |

信息不全时，以"△"占位（与原书示例一致），不得虚构事实。

## 五、输出定义

- **成品**：完整公函文本，组件顺序：〔信笺/机密标注〕→ 本函档号、来函档号 → 收信人地址→机构→职衔→姓名 → 上款（姓氏＋称谓＋冒号）→ 标题（可选）→ 正文（每段首行缩两格）→ 下款（首长职衔＋代行人括注）→ 附件 → 副本送 → 日期（信末左下方，自成一行，汉字或阿拉伯数字通篇一致）。
- **用字**：一律使用**简体中文**，严禁出现任何繁体中文字符（见"语言强制规则"）。背景说明：原书以繁体书写，香港政府公函惯例用繁体字、发内地函件可因应对象用简化字；本技能按强制规则统一输出简体。
- **检查清单**：① 档号齐全；② 上款仅一个称谓且后加冒号；③ 无启首语/提称语/启告语；④ 自称用"本"、对称用"贵"；⑤ 分段首行缩两格；⑥ 日期位置与用字一致；⑦ 附件与副本标注完整；⑧ 电邮另有标题栏且正文不留空；⑨ 全文无繁体中文字符。

## 六、适用场景与边界

**适用**：香港特区政府部门对外（市民、公私机构）及内部（同事）中文书信类公文；公务电邮；致内地政府单位或机构函件；酬酢函（谢函、贺辞、慰唁）。非政府用户撰写对港府的往来书信或仿古公文格式时亦可参照。

**边界**：
- 本技能只涵盖"公函"一册；备忘录、便笺、布告、通告等其他文类属同系列手册其他分册，不在本技能范围。
- 各决策局/部门另有内部规定的，从其规定；机密等级与递送方式、签署盖章细则详见原书《总论》分册，本技能不展开。
- 香港政府没有规定与内地机关通信的格式用语，`references/mainland-notes.md` 所列仅为两地的相异之处与参考做法。
- 附录用语须配合主旨与上文下理修订改写，不应生搬硬套（原书明示）。

## 七、最小示例

输入：△△署回复市民王△△ 6 月 2 日投诉信，案件仍在跟进（属"简复"场景，致个别市民）。

输出（简体中文）：

```
（部门信笺）

九龙牛头角
△△邨△楼△室
王△△先生

王先生：

六月二日来信收悉。本署现正跟进你的投诉，一有结果，定当另函详复。

△△署署长
（李△△  签名  代行）

二零△△年六月七日
```

要点对应：未能在十个历日内具体答复 → 先发简复；上款"姓氏＋先生＋冒号"；正文一段、首行缩两格；下款首长职衔＋代行人括注；日期信末左下方、汉字书写。
