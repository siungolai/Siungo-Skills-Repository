# 称谓用语全表

源自原书"概述·称谓用语"（第 2–5 页）。称谓是发信人对收信人的称呼。

## 一、尊称与头衔的基本选择

- 男性：先生
- 女性：女士（未婚已婚皆可）、小姐（未婚）
- 男女通用／性别不详：君
- 姓名或姓氏之后加头衔（多与职位、专业和学术资格有关）也是常用方式。

## 二、公函各部分的称谓方式

| 公函部分 | 用途 | 称谓方式与示例 |
|---|---|---|
| 信封上或内文开首的收信人地址 | 称呼收信人 | **全名加尊称**：王△△先生、黄△△女士、张林△△女士；**全名加头衔**：赵△△议员、李△△教授 |
| 上款 | 称呼收信人 | **姓氏加尊称**：廖先生、王女士、陈小姐、林太太；**姓氏加头衔**：李议员、陈博士、欧阳局长、林署长、刘司长、陆主席、谭医生、何教授、梁校长、黄经理、杨主任 |
| 内文 | 发信人自称及称呼自己的配偶 | 我、我们、本人；太太、内子、外子 |
| 内文 | 称呼收信人及其配偶 | 你、你们、阁下；你和太太、你和△先生；尊夫、尊夫人 |
| 内文 | 称呼第三方及其配偶 | 司长伉俪、署长和夫人、局长及其丈夫 |
| 内文 | 发信机构／团体自称 | 本局、本署、本会 |
| 内文 | 称呼收信机构／团体 | 贵署、贵会、贵校、贵公司 |

## 三、上款的特殊情况

1. **一信多发**：可用"各位市民"、"各位家长"、"各位租户"一类称谓。
2. **收信人姓名不详**：按职位或身分，用"执事先生"、"编辑先生"、"主席先生"等。
3. **只有英文姓名且性别不详**：在姓氏或全名后加"君"，如"Chan Tai-man"可写"Chan 君"或"Chan Tai-man 君"。
4. **多职衔**：上款一般只列一个称谓；因应通信目的和内容选用。例如收信人为区议员、身兼某委员会主席，信件内容与该委员会工作有关，上款可用"△主席"。
5. **宗教职衔**：主教、神父、牧师等，上款可用姓氏加头衔。收信人为"释△△法师"者，上款一般是**法号加头衔**，即"△△法师"，而非"释法师"。

## 四、注释细则（原书注 1–9）

1. **冠夫姓的已婚女性**：全称时夫姓先行、本姓次之，如"李黄△△议员"、"钱赵△△女士"；只提姓氏则用本姓，如"黄议员"、"赵女士"。
2. **勋章嘉奖缩写**：可在姓名后加英文缩写；多于一个时以级别最高的先行，同一类别只列级别最高的一个（如曾获 MBG、MBB、MH，列为"周△△先生，MBG, MH"）。部分头衔可用中文写出代替一般尊称，如"郑△△先生，GBM"可写"郑△△大紫荆勋贤"，"方△△女士，JP"可写"方△△太平绅士"。
3. **上款格式**：上款称谓后面用冒号（：），无须使用"敬启者"、"敬复者"等启首语，或"钧鉴"、"大鉴"等提称语。收信人的勋章或嘉奖无须在上款注明。
4. **自称不谦**：发信人或发信机构无须使用"鄙人"、"敝署"等谦称；内文自称或提及所属机构时，也不用细写或侧写以示谦卑。
5. **"你／您"**：公函一般用"你"称呼对方；表示亲切敬重可用"您"。在不影响文意的情况下，可少用"你、我、你们、我们"等代名词。
6. **不提行不离格**：内文称呼收信人或收信机构时，不用提行（另起一行）或离格（留空一个字位）。
7. **"阁下"**：收信人身分尊贵、地位崇高可用，现时多用于外交场合，如"大使阁下"、"总理阁下"。
8. **女性官员及其配偶**：第三方形式一般写法为"△△局局长郭黄△△女士及其丈夫郭△△先生"，再提及可简称"局长及其丈夫"；称呼对方并同时提及配偶可用"你和郭先生"。
9. **"伉俪"**：对夫妇的尊称。传统上写在"伉俪"一词之前的是男方的姓名或职衔，常见形式有"陈△△伉俪"、"陈△△博士伉俪"、"财政司司长伉俪"。
