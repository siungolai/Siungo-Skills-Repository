# 授权靠措辞判定，而非加载动作

commit-auto 允许模型自动调用，因此「技能被加载」不构成授权——加载只说明情境相关，授权必须由用户的话确认（见 SKILL.md §1.1–1.2）。替代方案是把授权与加载绑定：给 commit-auto 设 `disable-model-invocation: true`，让「用户亲手加载它」这个动作本身就是授权，SKILL.md 里那套措辞判定可以整段删掉。

被否决的理由：用户已明确表示自建 skill 的方向是全部允许模型自动调用。既有技能里只有 `commit-report` 与 `deploy-report` 显式写了 `disable-model-invocation: false`（等于允许），其余技能都没有这个键（同样是允许）；把新技能做成只能手动加载，与「全部可自动调用」的方向相反。而且节奏必须在功能闭合的当下被捕捉，用户未必每次都在场——若加载即授权，节奏就退化成由用户驱动。

> 记录一次事实更正：最初判断这件事时，只检测了该键是否存在而没看取值，误以为这两个技能禁止模型调用。实际取值为 `false`，即**允许**。本决策的结论不变，但理由已按事实重写。
