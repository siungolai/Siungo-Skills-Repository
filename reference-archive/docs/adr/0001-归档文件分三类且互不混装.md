# 归档文件分三类且互不混装

官方原文存档、一手资料镜像、整理文档这三类文件放在同一个归档目录里彼此可见，但绝不写进同一份文件。这不是洁癖——混装会让归档在读者手里失去可信度，而且这种损失是不可逆的：读者一旦发现某句话分不清是官方说的还是整理者推断的，就不会再信任整份文档，而这份文档的价值恰恰全在「哪句话可信」上。

于是每个文件被划入且只划入一类，判据是「这个文件的内容是谁在说话」。官方页面转写出来的 Markdown，读者打开时应当能确定「这里每一句都是官方原话，整理者只加了来源和采集时间」；而整理文档里的每一句话都应当能顺着出处标记追回它的依据。一手资料镜像则是第三种：它不说话，它只是原件，作用是让前两者的依据可以当场核对。

代价是读者要多打开几个文件——同一条结论在原文存档里和整理文档里各出现一次，想看清推导过程得来回翻。对一个以离线查阅为主的归档来说这个代价可以接受：真正高频使用的是整理文档（一处看全），原文存档是「我不信这条，去看原文」时的落点，而不是日常阅读对象。

如果把三者合并成一份「全能文档」，阅读体验确实更顺，但归档就从「可回溯的证据集合」退化成「一份看起来很全的说明文」——后者在官方更新后无法做增量对账，因为没法区分哪部分该跟着上游改、哪部分是整理者的判断。
